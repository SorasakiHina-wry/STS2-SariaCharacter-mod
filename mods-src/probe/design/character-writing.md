### 每个先古下面按「套」写对话

规则（游戏内的真实逻辑）：

- **套号 0** = 你和这位先古的**第 1 次**相遇（不含全存档首次）
- **套号 1** = 第 2 次，**套号 2** = 第 3 次……依次类推
- `firstVisitEver` = **全存档第一次**见这位先古（所有角色共用），只有第一次会触发
- 标了 `可重复: 是` 的套，会在没有更新套可用时**被重复抽取**
- 如果某位先古你**完全没写**，会自动回退到原版的通用台词（`ANY`），不会出 bug

写法：一行一句，前缀标明谁在说话。

```
[古] 先古之民说的话
[她] 塞雷娅说的话
[钮] 继续按钮上的字（可省略，默认「继续」）
```

## 三、角色选择界面背景图规格

**2560 × 1200 像素（长宽比 32 : 15 ≈ 2.133 : 1）**

依据：我拆开原版 5 个角色的背景场景（`res://scenes/screens/char_select/char_select_bg_*.tscn`），它们的根节点尺寸完全一致：

```
offset_left = -960    offset_right  = 1600   → 宽 2560
offset_top  = -521    offset_bottom =  679   → 高 1200
pivot_offset = (1280, 600)                   → 以屏幕中心为锚点
```

也就是说背景是**以屏幕中心为锚点、比 16:9 更宽的一张大图**，这样在超宽屏上也不会露边。

要点：

- **中间 1920×1080 区域一定会完整显示**，重要内容（人物、装饰）放这里；
- 左右两侧各约 320px 可能被裁掉，放渐变/背景纹理就行；
- 格式：PNG 即可（也支持 jpg/svg）；有透明区域也没问题。

> 如果你更想做「和原版一样的动态背景」（Spine 立绘 + 光效），那就不是一张图，而是一个场景 —— 需要额外的 Spine 资源和层级，告诉我我再单独开一节规格。
