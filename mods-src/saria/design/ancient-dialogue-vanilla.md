# 原版角色 × 先古之民 对话一览

> 由 `tools/export_ancient_dialogue.py` 从游戏内 `ancients.json` 自动导出，**不要手改**。
> 格式说明见 [`character-writing.md`](character-writing.md)。
> 方括号里是先古（`[古]`）或该角色；`[钮]` 是继续按钮上的字（与原版不同时才列出）。
> 原文里的换行 `\n` 在这里直接显示成下一行（该行没有前缀）。

## 富文本标记说明

| 标记 | 作用 | 本文档中出现 |
|---|---|---|
| `[gold]` | 金色高亮：关键词、名字、数值 | ✓ |
| `[blue]` | 蓝色高亮：次要关键词 |  |
| `[red]` | 红色高亮：危险、敌意、负面 | ✓ |
| `[green]` | 绿色高亮：正面、恢复 |  |
| `[orange]` | 橙色高亮 | ✓ |
| `[purple]` | 紫色高亮 |  |
| `[pink]` | 粉色高亮 |  |
| `[aqua]` | 青色高亮 | ✓ |
| `[b]` | 粗体 | ✓ |
| `[i]` | 斜体（常与 font_size 一起做旁白） | ✓ |
| `[font_size=22]` | 字号，22 是原版旁白/拟声用的小字号 | ✓ |
| `[center]` | 整段居中 |  |
| `[sine]` | 上下缓慢起伏的波浪（飘忽、幽灵感；幅度约 0.8 像素） | ✓ |
| `[jitter]` | 快速随机抖动（颤抖、情绪激动；幅度约 3 像素） | ✓ |
| `[thinky_dots]` | 逐字轻微上浮的波浪，用来表现「正在思考/正在说」 | ✓ |
| `[shake]` | Godot 内置抖动效果 |  |
| `[rainbow]` | Godot 内置彩虹渐变 |  |
| `[fade_in]` | 淡入出现（常用于旁白） |  |
| `[fly_in]` | 飞入出现 |  |
| `[scramble]` | 乱码/解码效果（不可名状的低语） |  |
| `[lb]` | 左方括号：`[lb]文字` 显示成「文字 |  |
| `[rb]` | 右方括号：`文字[rb]` 显示成文字」 |  |

> 颜色类标记（gold/blue/red/…）只改颜色、不改语义，和卡牌描述里的高亮是同一套。
